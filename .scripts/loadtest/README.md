# Load-test tools

`fake_llm.py` provides a configurable local model stub.
`drive.py` submits jobs and reports terminal states, latency, and concurrency.
Use [the load-test procedure](../../docs/internal/how-to-run-load-tests.md) to configure and run a measurement.
See [validation results](../../docs/internal/validation-results.md) for current evidence limits.
